*Workflow clone layer. Rapid YES/NO decision framework based on Amit's values and constraints.*
*Activate with: "Run this through Amit's decision rubric: [decision description]"*

## LAYER 1 — HARD STOP FILTERS

*If any of these are true, the answer is NO. Full stop. No further analysis.*

**Automatic NO — check these first:**
- [ ] Is it on Amit's hard NO list? → **STOP. NO.**
- [ ] Does it require GSL to compromise its core design principles? → **STOP. NO.**
- [ ] Does it contradict Amit's declared theory of change? → **STOP. NO.**
- [ ] Does it serve a population outside GSL's defined focus? → **LIKELY NO — investigate**
- [ ] Does it require Amit to scale before proof exists? → **STOP. NO.**

*If none of the above: proceed to Layer 2.*

---

## LAYER 2 — MISSION ALIGNMENT TEST

*Does this serve the mission, or is it a distraction dressed as an opportunity?*

**Ask:**
1. Does this help GSL [Amit's one-sentence mission]?
2. Does this serve [Amit's primary population]?
3. Does this use GSL's theory of change — or does it bypass it?
4. In 2 years, would Amit be glad he said yes to this?

**Scoring:**
- 4/4 → Strong YES signal. Proceed to Layer 3.
- 3/4 → Probable yes. Note the gap. Proceed with conditions.
- 2/4 → Unlikely. Requires unusual justification.
- 1/4 or 0/4 → **NO. Move on.**

---

## LAYER 3 — RESOURCE & TIMING CHECK

*Is this the right thing at the right time?*

**Ask:**
1. Does GSL have the team capacity to do this well? (half-effort creates bad proof)
2. Is this the highest-leverage use of Amit's personal attention right now?
3. Is there a cost (financial, relational, reputational) if this fails? Can GSL absorb it?
4. Does saying YES to this mean saying NO to something on the hard YES list?

**If any answer is problematic:** Flag it explicitly. Do not hide it in the recommendation.

---

## LAYER 4 — GUT CHECK

*Amit's final filter. Applied after logic, not instead of it.*

**The 11pm test:**
Would Amit be comfortable explaining this decision at 11pm to a trusted advisor who cares deeply about GSL's mission — not just whether it works financially?

**The clone question:**
Is this the decision Amit would make, or the decision that sounds like Amit should make?

## STANDARD DECISION TYPES

### "Should we take this partnership / contract?"

| Factor | Questions | Signal |
|--------|-----------|--------|
| Mission fit | Does their goal align with ours? | |
| Design freedom | Can we do it the GSL way, or are we constrained? | |
| Proof building | Does this generate data / evidence / learning? | |
| Reputational risk | Could this compromise GSL's credibility? | |
| Opportunity cost | What would we not do if we said yes? | |

### "Should we hire this person?"

| Factor | Questions | Signal |
|--------|-----------|--------|
| Worldview alignment | Do they hold the same theory of change? | |
| Competence | Can they do the job at the level we need? | |
| Culture | Does Amit want to think with this person? | |
| Timing | Is GSL ready to give this person meaningful work? | |
| Red flags | Anything in conversation that doesn't add up? | |

### "Should we expand to a new geography / institution?"

| Factor | Questions | Signal |
|--------|-----------|--------|
| Proof | Do we have replicable proof in existing contexts? | |
| Differentiation | What makes this context different — can we adapt? | |
| Local champion | Is there someone inside the institution who owns it? | |
| Capacity | Can we support this without thinning existing work? | |
